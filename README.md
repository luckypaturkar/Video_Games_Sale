# Video-Games-Sales-Analysis

Welcome to the Video Games Sales Analysis project repository! This project focuses on analyzing video game sales data to understand market trends, popular gaming genres, platform performance, publisher performance, and regional sales distribution. Using Python libraries such as Pandas, Matplotlib, and Seaborn, this project explores historical video game sales data and presents meaningful insights through different visualizations.

This README file provides essential information about the project, its features, tools, and instructions to get started.

## Getting Started

* **Data Preparation:** Import the video game sales dataset and prepare the data for analysis by checking data types and handling missing values.
* **Exploratory Data Analysis (EDA):** Explore the dataset to understand sales patterns, gaming trends, and relationships between different variables.
* **Data Visualization:** Create different charts and graphs using Matplotlib and Seaborn to represent sales performance.
* **Insights Generation:** Analyze the results to identify the most popular games, genres, platforms, publishers, and regions.

## Features

* **Genre Sales Analysis:** Identify the most popular video game genres based on total and average global sales.
* **Regional Sales Analysis:** Analyze video game sales across North America, Europe, Japan, and Other regions.
* **Top-Selling Games Analysis:** Identify the top 10 best-selling video games based on global sales.
* **Platform Performance Analysis:** Compare different gaming platforms based on their total global sales.
* **Publisher Performance Analysis:** Analyze the performance of major video game publishers across different regions.
* **Gaming Trends Analysis:** Explore changes in genre preferences and sales performance over the years.
* **Data Visualization:** Present analytical results using bar plots, pie charts, and line plots.

## Analysis Breakdown

* **Genre Analysis:** Action games recorded the highest total global sales at 1,751.18 million copies, followed by Sports games at 1,330.93 million copies.
* **Regional Sales Analysis:** North America recorded the highest sales at 4,392.95 million copies, followed by Europe with 2,434.13 million copies.
* **Top-Selling Games Analysis:** Wii Sports ranked first with 82.74 million copies sold globally, followed by Super Mario Bros. with 40.24 million copies.
* **Platform Performance Analysis:** PlayStation 2 (PS2) recorded the highest total global sales at 1,255.64 million copies.
* **Publisher Performance Analysis:** Nintendo recorded the highest sales among publishers in North America, Europe, and Japan.
* **Gaming Trends Analysis:** Action games dominated the sales charts during several years, particularly between 2007 and 2015.

## Usage

You can access, view, and edit this project using Python and Jupyter Notebook.

To run this project, you need to install the required Python libraries:

```bash
pip install pandas matplotlib seaborn jupyter
```

After installing the libraries, follow these steps:

1. Download or clone this repository.
2. Download the video game sales dataset (`vgsales.csv`).
3. Place the dataset inside the `Datasets` folder, as expected by the notebook.
4. Open Jupyter Notebook or Jupyter Lab.
5. Open the `Video_Games_Sales.ipynb` file.
6. Run all the cells to perform the analysis and generate visualizations.
